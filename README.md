# AI Sketchbook

Teaching experiments at the University of New Mexico: classroom activities, assignments, and course policies with prompts, context, and notes on what happened.

[View AI Sketchbook](https://amaranth.unm.edu/ai-sketchbook/).

Research experiments have moved to the companion [AI Workbench](https://amaranth.unm.edu/ai-workbench/). See [SITE-SPLIT.md](SITE-SPLIT.md) for the staged standalone source and publication order.

## Edit and preview

- Copy `teaching/_sketch-template.md` or `policy/_sketch-template.md` and preserve its front-matter fields.
- Write in Markdown with the existing includes. Follow [STYLE-GUIDE.md](STYLE-GUIDE.md).
- Run `bundle exec jekyll serve --port 4003`, then open `http://localhost:4003/ai-sketchbook/`.
- Build with `LANG=en_US.UTF-8 LC_ALL=en_US.UTF-8 bundle exec jekyll build`.

Printing the teaching index from the browser gives one landscape letter poster per card. Research URLs are compatibility redirects; their old image and PDF files remain available for existing external links.
